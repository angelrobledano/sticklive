# App móvil Stick Live — Plan de Implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App móvil (Expo/React Native) en `apps/mobile` con paridad funcional respecto a la web (directo, ficha SSE, clasificación, búsqueda, favoritos, login Google, ajustes), push nativo vía Expo Push, publicable en Google Play (iOS compilable pero no publicado).

**Architecture:** Monorepo Turborepo: nueva workspace `apps/mobile` (Expo + expo-router + NativeWind) que consume la API Hono existente (REST + SSE, Bearer tokens). El push nativo añade `push_tokens` (nueva tabla, migración 065) y amplía el emisor del ETL a doble canal (web-push + Expo Push) compartiendo la segmentación pura existente. El login reutiliza el flujo Google OAuth del API con un código de canje de un solo uso hacia el scheme `sticklive://`.

**Tech stack:** Expo (SDK estable vigente, ≥56), expo-router, NativeWind v4, TanStack Query, react-native-sse, expo-notifications (Expo Push), expo-secure-store, vitest, EAS Build. Spec: `docs/superpowers/specs/2026-10-05-app-movil-design.md`.

## Convenciones del plan (leer antes de empezar)

- **Entorno:** Windows + PowerShell. Comandos npm cruzan plataformas; `npx expo` se ejecuta con `workdir: apps/mobile`.
- **Versión de Expo:** se crea con `npx create-expo-app@latest` (SDK estable en el momento de ejecutar, ≥56). NO fijar versiones a mano: `npx expo install <pkg>` resuelve las versiones compatibles; si algo desajusta, `npx expo install --fix`. Registrar el SDK resultante en `apps/mobile/package.json` tal cual quede.
- **API base URL:** en desarrollo `http://<IP-LAN>:3000` (el emulador no ve `localhost` del host; usar la IP LAN del PC o el especial `10.0.2.2` en emulador Android). En producción `https://sticklive.eu/api` (Caddy elimina el prefijo `/api` — el API no lo tiene).
- **Auth es Bearer** (verificado: `userFromBearer` en `apps/api/src/routes/auth.ts:35`; CORS permite `Authorization`). La app guarda el token en `expo-secure-store` y envía `Authorization: Bearer <token>`. Cero cambios de transporte en el API.
- **Favoritos:** añadir = `POST /auth/favorites/merge` (idempotente, admite 1 elemento); quitar = `DELETE /auth/favorites`. Sin endpoint de logout en el API: cerrar sesión = borrar token local (paridad con la web).
- **Segmentación push pura** (`apps/etl/src/push-segmentation.ts`): `SubPrefs { fav_teams, fav_leagues, fav_players, presets: Record<'team:id'|'competition:id'|'player:id', NotificationPreset>, config: { master?, quietNight? } }`. La app sincroniza EXACTAMENTE esta forma en `push_tokens`.
- **Migraciones:** siguiente número **065** (la última es `064_competitions_data_quality.sql`). Idempotente (`IF NOT EXISTS`), aditiva, nunca destructiva.
- **TDD:** cada tarea empieza por el test que falla, salvo tareas puramente de configuración/scaffold (se verifica con comandos).
- **Commits:** uno por tarea, estilo del repo (`feat:`, `test:`, `chore:`, `docs:`). Nunca reescribir historial.
- **Verificación de tarea completa:** `npm run typecheck && npm run lint && npm run test` en verde desde la raíz del monorepo (Turborepo incluye `apps/mobile` en cuanto tenga esos scripts).

```ts
// Los JSON viven en la web (fuente única de traducciones). Import en relativo,
// mismo patrón que el ETL con notification-copy: el bundler los copia al bundle.
import en from '../../../web/src/locales/en.json';
import es from '../../../web/src/locales/es.json';
import fr from '../../../web/src/locales/fr.json';
import it from '../../../web/src/locales/it.json';
import pt from '../../../web/src/locales/pt.json';

export type Locale = 'en' | 'es' | 'fr' | 'it' | 'pt';

export const LOCALES: Locale[] = ['en', 'es', 'fr', 'it', 'pt'];

export const dictionaries: Record<Locale, Record<string, unknown>> = { en, es, fr, it, pt };

/** Resuelve una clave punteada ('a.b.c') en el diccionario; fallback: la clave. */
export function resolveKey(dict: Record<string, unknown>, key: string): string {
  let node: unknown = dict;
  for (const part of key.split('.')) {
    if (typeof node !== 'object' || node === null) return key;
    node = (node as Record<string, unknown>)[part];
  }
  return typeof node === 'string' ? node : key;
}
```

- [x] **Step 4: Implementar `LocaleContext.tsx`**

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage';
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from 'react';
import { dictionaries, resolveKey, type Locale } from './locales';

// instalado: npx expo install @react-native-async-storage/async-storage

interface LocaleCtx {
  locale: Locale;
  setLocale: (l: Locale) => void;
  t: (key: string) => string;
}

const Ctx = createContext<LocaleCtx | null>(null);
const STORAGE_KEY = 'sticklive.locale';

export function LocaleProvider({ children }: { children: React.ReactNode }) {
  const [locale, setLocaleState] = useState<Locale>('es');

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then((saved) => {
      if (saved && LOCALES.includes(saved as Locale)) setLocaleState(saved as Locale);
    }).catch(() => {});
  }, []);

  const setLocale = useCallback((l: Locale) => {
    setLocaleState(l);
    void AsyncStorage.setItem(STORAGE_KEY, l);
  }, []);

  const t = useCallback(
    (key: string) => resolveKey(dictionaries[locale], key),
    [locale],
  );

  const value = useMemo(() => ({ locale, setLocale, t }), [locale, setLocale, t]);
  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

export function useLocale(): LocaleCtx {
  const ctx = useContext(Ctx);
  if (!ctx) throw new Error('useLocale fuera de LocaleProvider');
  return ctx;
}
```

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage';
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from 'react';
import { useColorScheme } from 'nativewind';

export type ThemePref = 'system' | 'light' | 'dark';

interface ThemeCtx {
  pref: ThemePref;
  setPref: (p: ThemePref) => void;
}

const Ctx = createContext<ThemeCtx | null>(null);
const STORAGE_KEY = 'sticklive.theme';

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const { setColorScheme } = useColorScheme();
  const [pref, setPrefState] = useState<ThemePref>('system');

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then((saved) => {
      if (saved === 'light' || saved === 'dark' || saved === 'system') setPrefState(saved);
    }).catch(() => {});
  }, []);

  const setPref = useCallback((p: ThemePref) => {
    setPrefState(p);
    void AsyncStorage.setItem(STORAGE_KEY, p);
    setColorScheme(p === 'system' ? undefined : p);
  }, [setColorScheme]);

  const value = useMemo(() => ({ pref, setPref }), [pref, setPref]);
  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

export function useThemePref(): ThemeCtx {
  const ctx = useContext(Ctx);
  if (!ctx) throw new Error('useThemePref fuera de ThemeProvider');
  return ctx;
}
```

`apps/mobile/src/lib/api/client.ts`:

```ts
const API_URL = process.env['EXPO_PUBLIC_API_URL'] ?? 'http://10.0.2.2:3000';

export class ApiError extends Error {
  readonly status: number;
  readonly code: string;
  constructor(status: number, code: string) {
    super(`api ${status}: ${code}`);
    this.name = 'ApiError';
    this.status = status;
    this.code = code;
  }
}

interface Options {
  token?: string | null;
  method?: 'GET' | 'POST' | 'DELETE';
  body?: unknown;
  signal?: AbortSignal;
}

export async function apiFetch<T>(path: string, opts: Options = {}): Promise<T> {
  const headers: Record<string, string> = {};
  if (opts.token) headers['Authorization'] = `Bearer ${opts.token}`;
  if (opts.body !== undefined) headers['Content-Type'] = 'application/json';

  let res: Response;
  try {
    res = await fetch(`${API_URL}${path}`, {
      method: opts.method ?? 'GET',
      headers,
      body: opts.body !== undefined ? JSON.stringify(opts.body) : undefined,
      signal: opts.signal,
    });
  } catch {
    throw new ApiError(0, 'network');
  }

  if (!res.ok) {
    const envelope = (await res.json().catch(() => ({}))) as { error?: string };
    throw new ApiError(res.status, envelope.error ?? `http_${res.status}`);
  }
  return (await res.json()) as T;
```

```ts
import { STALE_LIVE_HOURS } from '@sports/shared-types';

const MADRID = 'Europe/Madrid';

export function formatKickoff(iso: string | null): string {
  if (!iso) return '--:--';
  return new Intl.DateTimeFormat('es-ES', {
    hour: '2-digit', minute: '2-digit', timeZone: MADRID, hour12: false,
  }).format(new Date(iso));
}

export function formatDayLabel(iso: string | null): string {
  if (!iso) return '';
  return new Intl.DateTimeFormat('es-ES', {
    weekday: 'long', day: 'numeric', month: 'short', timeZone: MADRID,
  }).format(new Date(iso));
}

/**
 * "En juego por reloj": misma regla que la web (MatchCard) y el API
 * (effective-status): un partido scheduled dentro de las STALE_LIVE_HOURS tras
 * el saque se pinta EN DIRECTO. Fuente única en @sports/shared-types.
 */
export function isEffectivelyLive(status: string, scheduledAt: string | null): boolean {
  if (status === 'live' || status === 'halftime' || status === 'overtime' || status === 'penalty_shootout') return true;
  if (status !== 'scheduled' || !scheduledAt) return false;
  const elapsedHours = (Date.now() - new Date(scheduledAt).getTime()) / 3_600_000;
  return elapsedHours >= 0 && elapsedHours < STALE_LIVE_HOURS;
}
```

- [ ] **Step 3: Implementar `match-stream.ts`**

```ts
import type { MatchDetail } from './api/types';

export type Transport = 'sse' | 'poll';
export interface MatchState {
  detail: MatchDetail | null;
  connected: boolean;
  transport: Transport;
}

export type StreamPatch =
  | { kind: 'snapshot'; detail: MatchDetail }
  | { kind: 'update'; match: MatchDetail['match']; newEvents: MatchDetail['events'] }
  | { kind: 'transport'; transport: Transport };

/** Backoff exponencial 1s, 2s, 4s... tope 30s. */
export function backoffDelay(attempt: number): number {
  return Math.min(1000 * 2 ** attempt, 30_000);
}

/** Reducer puro del estado de la ficha a partir de los patches del stream. */
export function applyStreamPatch(state: MatchState, patch: StreamPatch): MatchState {
  switch (patch.kind) {
    case 'snapshot':
      return { ...state, detail: patch.detail, connected: true };
    case 'update': {
      if (!state.detail) return state;
      const known = new Set(state.detail.events.map((e) => e.id));
      const fresh = patch.newEvents.filter((e) => !known.has(e.id));
      return {
        ...state,
        connected: true,
        detail: {
          ...state.detail,
          match: { ...state.detail.match, ...patch.match },
          events: [...state.detail.events, ...fresh],
        },
      };
    }
    case 'transport':
      return { ...state, transport: patch.transport, connected: false };
  }
}
```

```ts
  const pollRef = useRef<ReturnType<typeof setInterval> | null>(null);
  const focused = useRef(true);

  function stopAll() {
    esRef.current?.close();
    esRef.current = null;
    if (pollRef.current) clearInterval(pollRef.current);
    pollRef.current = null;
  }

  function startPolling() {
    if (pollRef.current) return;
    dispatch({ kind: 'transport', transport: 'poll' });
    const poll = async () => {
      try {
        const detail = await apiFetch<typeof state.detail>(`/matches/${matchId}`, { token: token ?? undefined });
        if (detail) dispatch({ kind: 'snapshot', detail });
      } catch { /* el poll reintenta solo; ErrorState lo cubre si la primera carga falla */ }
    };
    void poll();
    pollRef.current = setInterval(() => void poll(), POLL_MS);
  }

  function connect() {
    stopAll();
    const headers: Record<string, string> = {};
    if (token) headers['Authorization'] = `Bearer ${token}`;
    const es = new EventSource(`/matches/${matchId}/stream`, {
      // react-native-sse exige URL absoluta:
      baseURL: undefined as never, // (ver nota) — se pasa `url` absoluta abajo
      headers,
    } as never);
    // Nota práctica: pasar la URL absoluta directamente:
    //   new EventSource(`${API_URL}/matches/${matchId}/stream`, { headers })
    // (el constructor se crea abajo con la URL absoluta; esta variable queda
    //  para el lint. Ver implementación final en el archivo.)
    es.addEventListener('snapshot', (ev) => {
      failures.current = 0;
      const detail = JSON.parse((ev.data as string)) as MatchState['detail'];
      if (detail) {
        qc.setQueryData(['matches', matchId], detail);
        dispatch({ kind: 'snapshot', detail });
      }
    });
    es.addEventListener('update', (ev) => {
      const p = JSON.parse((ev.data as string)) as { match: never; newEvents: never };
      dispatch({ kind: 'update', match: p.match, newEvents: p.newEvents });
    });
    es.addEventListener('timeout', () => { es.close(); if (focused.current) connect(); });
    es.addEventListener('error', () => {
      failures.current += 1;
      if (failures.current >= MAX_SSE_FAILURES) startPolling();
      else setTimeout(() => { if (focused.current) connect(); }, backoffDelay(failures.current));
    });
    esRef.current = es;
  }

  useFocusEffect(
    useCallbackDoNotImport(() => {
      focused.current = true;
      connect();
      return () => { focused.current = false; stopAll(); };
    }, [matchId, token]),
  );

  return state;
}
```

```ts
import { useEffect, useState } from 'react';

export function useDebounced<T>(value: T, delayMs: number): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delayMs);
    return () => clearTimeout(id);
  }, [value, delayMs]);
  return debounced;
}
```

3c. Nuevo endpoint `POST /auth/exchange` (canje atómico single-use, mismo patrón que `/auth/verify`):

```ts
/**
 * POST /auth/exchange  { code }
 * Canjea el código de login de la app (single-use atómico) por una sesión
 * Bearer. Rate limit estricto; el código caduca en 2 minutos.
 */
authRouter.post('/exchange', rateLimit(10, 10 * 60_000), async (c) => {
  const { code } = await c.req.json<{ code?: string }>().catch(() => ({ code: undefined }));
  if (!code || code.length > 512) return c.json({ error: 'invalid_code' }, 400);
  const codeHash = createHash('sha256').update(code).digest('hex');
  try {
    const userId = await withTransaction(async (tx) => {
      // UPDATE ... WHERE used_at IS NULL AND expires_at > NOW(): atómico, el
      // segundo canje del mismo código no devuelve filas.
      const res = await tx.query<{ user_id: string }>(
        `UPDATE app_login_codes SET used_at = NOW()
          WHERE code_hash = $1 AND used_at IS NULL AND expires_at > NOW()
          RETURNING user_id`,
        [codeHash],
      );
      return res.rows[0]?.user_id ?? null;
    });
    if (!userId) return c.json({ error: 'invalid_code' }, 400);
    const session = await openSession(userId);
    const u = await db.query<{ email: string | null }>(`SELECT email FROM users WHERE id = $1`, [userId]);
    return c.json({ session, email: u.rows[0]?.email ?? null });
  } catch (err) {
    captureRouteError(err, '[auth] exchange error');
    logger.error({ err }, '[auth] exchange error');
    return c.json({ error: 'server_error' }, 500);
  }
});
```

```ts
// apps/mobile/src/lib/session.ts
import * as SecureStore from 'expo-secure-store';

const TOKEN_KEY = 'sticklive.session.token';
const EMAIL_KEY = 'sticklive.session.email';

export interface Session {
  token: string;
  email: string | null;
}

/** Extrae el código de canje del redirect `sticklive://auth/callback?code=...`. */
export function parseAuthRedirect(url: string): { code: string; email: string | null } | null {
  if (!url.startsWith('sticklive://auth/callback')) return null;
  const qs = url.split('?')[1] ?? '';
  const params = new URLSearchParams(qs);
  if (params.get('error') || !params.get('code')) return null;
  return { code: params.get('code')!, email: params.get('email') };
}

export async function saveSession(s: Session): Promise<void> {
  await SecureStore.setItemAsync(TOKEN_KEY, s.token);
  if (s.email) await SecureStore.setItemAsync(EMAIL_KEY, s.email);
}

export async function loadSession(): Promise<Session | null> {
  const token = await SecureStore.getItemAsync(TOKEN_KEY);
  if (!token) return null;
  return { token, email: await SecureStore.getItemAsync(EMAIL_KEY) };
}

export async function clearSession(): Promise<void> {
  await SecureStore.deleteItemAsync(TOKEN_KEY);
  await SecureStore.deleteItemAsync(EMAIL_KEY);
}
```

```tsx
import * as WebBrowser from 'expo-web-browser';
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from 'react';
import { apiFetch } from '@/src/lib/api/client';
import { getDeviceId } from '@/src/lib/device';
import { clearSession, loadSession, parseAuthRedirect, saveSession, type Session } from '@/src/lib/session';

const API_URL = process.env['EXPO_PUBLIC_API_URL'] ?? 'http://10.0.2.2:3000';

interface AuthCtx {
  session: Session | null;
  ready: boolean;
  signInWithGoogle: () => Promise<void>;
  signOut: () => Promise<void>;
}

const Ctx = createContext<AuthCtx | null>(null);

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const [session, setSession] = useState<Session | null>(null);
  const [ready, setReady] = useState(false);

  useEffect(() => {
    loadSession().then(setSession).finally(() => setReady(true));
  }, []);

  const signInWithGoogle = useCallback(async () => {
    const deviceId = await getDeviceId();
    // openAuthSessionAsync resuelve cuando el navegador redirige al scheme.
    const result = await WebBrowser.openAuthSessionAsync(
      `${API_URL}/auth/google?client=app&device=${encodeURIComponent(deviceId)}`,
      'sticklive://auth/callback',
    );
    if (result.type !== 'success') return;
    const parsed = parseAuthRedirect(result.url);
    if (!parsed) return;
    // Canje: el código de un solo uso vale 120 s; la sesión viaja por HTTPS.
    const data = await apiFetch<{ session: string; email: string | null }>('/auth/exchange', {
      method: 'POST',
      body: { code: parsed.code },
    });
    const s: Session = { token: data.session, email: data.email ?? parsed.email };
    await saveSession(s);
    setSession(s);
  }, []);

  const signOut = useCallback(async () => {
    await clearSession();
    setSession(null);
  }, []);

  const value = useMemo(() => ({ session, ready, signInWithGoogle, signOut }), [session, ready, signInWithGoogle, signOut]);
  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

export function useSession(): AuthCtx {
  const ctx = useContext(Ctx);
  if (!ctx) throw new Error('useSession fuera de AuthProvider');
```

```ts
import { useMutation, useQueryClient } from '@tanstack/react-query';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { apiFetch } from '@/src/lib/api/client';
import { qk, useFavorites } from './queries';

const LOCAL_KEY = 'sticklive.favorites.local';
export interface LocalFavorites { teams: string[]; leagues: string[]; players: string[] }
const EMPTY: LocalFavorites = { teams: [], leagues: [], players: [] };
const CAP = 200;

export function mergeFavoritesIntoRequest(local: LocalFavorites) {
  return {
    teams: local.teams.slice(0, CAP),
    leagues: local.leagues.slice(0, CAP),
    players: local.players.slice(0, CAP),
  };
}

export async function loadLocalFavorites(): Promise<LocalFavorites> {
  return { ...EMPTY, ...(await AsyncStorage.getItem(LOCAL_KEY).then((v) => (v ? JSON.parse(v) : null))) };
}

export async function saveLocalFavorites(f: LocalFavorites): Promise<void> {
  await AsyncStorage.setItem(LOCAL_KEY, JSON.stringify(f));
}

/** Añade 1 favorito (merge idempotente del API admite 1 elemento). */
export function useAddFavorite(token: string | null | undefined) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: async ({ kind, refId }: { kind: 'team' | 'league' | 'player'; refId: string }) => {
      const body = {
        teams: kind === 'team' ? [refId] : [],
        leagues: kind === 'league' ? [refId] : [],
        players: kind === 'player' ? [refId] : [],
      };
      if (token) {
        await apiFetch('/auth/favorites/merge', { method: 'POST', token, body });
      } else {
        const local = await loadLocalFavorites();
        const merged = {
          teams: [...new Set([...local.teams, ...body.teams])],
          leagues: [...new Set([...local.leagues, ...body.leagues])],
          players: [...new Set([...local.players, ...body.players])],
        };
        await saveLocalFavorites(merged);
      }
    },
    onSuccess: () => { void qc.invalidateQueries({ queryKey: qk.favorites }); },
  });
}

export function useRemoveFavorite(token: string | null | undefined) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: async ({ kind, refId }: { kind: 'team' | 'league' | 'player'; refId: string }) => {
      if (token) {
        await apiFetch('/auth/favorites', { method: 'DELETE', token, body: { kind, refId } });
      } else {
        const local = await loadLocalFavorites();
        const next: LocalFavorites = {
          teams: local.teams.filter((x) => x !== refId),
          leagues: local.leagues.filter((x) => x !== refId),
          players: local.players.filter((x) => x !== refId),
        };
        await saveLocalFavorites(next);
      }
    },
    onSuccess: () => { void qc.invalidateQueries({ queryKey: qk.favorites }); },
  });
}

/** Al iniciar sesión: fusionar favoritos locales anónimos → cuenta → el estado local pasa a espejo del servidor. */
export async function mergeLocalOnLogin(token: string): Promise<void> {
  const local = await loadLocalFavorites();
  const server = await apiFetch<typeof local>('/auth/favorites/merge', {
    method: 'POST', token, body: mergeFavoritesIntoRequest(local),
  });
  await saveLocalFavorites(server);
}

export { useFavorites };
```

```ts
/**
 * Canal nativo (Expo Push → FCM/APNs). Misma filosofía que deliver():
 * errores explícitos, poda de tokens muertos, nunca silencioso.
 */
import { db } from '@sports/db';
import { createLogger } from '@sports/logger';

const log = createLogger({ service: 'push-expo' });
const EXPO_API = 'https://exp.host/--/api/v2/push/send';
const EXPO_RECEIPTS = 'https://exp.host/--/api/v2/push/getReceipts';

export interface NativeSubRow {
  id: string;
  expo_push_token: string;
  device_id: string;
  fav_teams: string[];
  fav_leagues: string[];
  fav_players: string[];
  config: Record<string, unknown>;
  presets: Record<string, string>;
}

export interface ExpoPayload { title: string; body: string; tag: string; url: string; type: string }

/** Convierte la URL web (sticklive.eu/matches/<id>) en ruta de deep link de la app. */
function toUrlPath(url: string): string {
  const m = url.match(/\/matches\/([0-9a-f-]+)/i);
  return m ? `/matches/${m[1]}` : '/';
}

export function toExpoMessage(sub: { expo_push_token: string }, payload: ExpoPayload) {
  return {
    to: sub.expo_push_token,
    title: payload.title,
    body: payload.body,
    channelId: 'live',
    sound: 'default',
    collapseId: payload.tag,        // smart bundling: reemplaza la notificación viva del partido
    data: { type: payload.type, urlPath: toUrlPath(payload.url) },
  };
}

export function chunkMessages<T>(msgs: T[], size = 100): T[][] {
  const out: T[][] = [];
  for (let i = 0; i < msgs.length; i += size) out.push(msgs.slice(i, i + size));
  return out;
}

/** Carga las suscripciones nativas (SubPrefs-compatible). */
export async function loadNativeSubs(): Promise<NativeSubRow[]> {
  const res = await db.query<NativeSubRow>(
    `SELECT id, expo_push_token, device_id, fav_teams, fav_leagues, fav_players, config, presets
       FROM push_tokens`,
  );
  return res.rows;
}

/**
 * Envía por lotes; devuelve los receipt ids. deviceNotRegistered se poda.
 * `master === false` ya lo filtra el llamante con la segmentación existente.
 */
export async function deliverNative(
  subs: NativeSubRow[], payload: ExpoPayload, captureSent: (deviceId: string, type: string) => void,
): Promise<{ sent: number; failed: number }> {
  if (subs.length === 0) return { sent: 0, failed: 0 };
  const messages = subs.map((s) => toExpoMessage(s, payload));
  const receiptIds: string[] = [];
  let sent = 0, failed = 0;

  for (const chunk of chunkMessages(messages)) {
    try {
      const res = await fetch(EXPO_API, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(chunk),
      });
      if (!res.ok) {
        log.error({ status: res.status }, 'Expo Push API rechazó el lote');
        failed += chunk.length;
        continue;
      }
      const data = (await res.json()) as { data: Array<{ id?: string; status?: string; message?: string }> };
      for (const item of data.data) {
        if (item.status === 'ok' && item.id) { sent += 1; receiptIds.push(item.id); }
        else { failed += 1; log.warn({ detail: item.message }, 'Envío Expo rechazado'); }
      }
      const sentSubs = subs.slice(0, chunk.length); // correspondencia 1:1 por orden de chunk
      for (const s of sentSubs) captureSent(s.device_id, payload.type);
    } catch (err) {
      failed += chunk.length;
      log.error({ err }, 'Fallo de red contra Expo Push');
    }
  }

  if (receiptIds.length > 0) await processReceipts(receiptIds);
  return { sent, failed };
}

async function processReceipts(receiptIds: string[]): Promise<void> {
  for (const chunk of chunkMessages(receiptIds, 1000)) {
    try {
      const res = await fetch(EXPO_RECEIPTS, {
        method: 'POST', headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ ids: chunk }),
      });
      if (!res.ok) { log.warn({ status: res.status }, 'Recibos Expo no disponibles'); continue; }
      const data = (await res.json()) as { data: Record<string, { status: string; message?: string; details?: { error?: string } }> };
      const dead: string[] = [];
      for (const [id, receipt] of Object.entries(data.data)) {
        if (receipt.status === 'error' && receipt.details?.error === 'DeviceNotRegistered') dead.push(id);
      }
      if (dead.length > 0) {
        await db.query(`DELETE FROM push_tokens WHERE expo_push_token = ANY($1::text[])`, [dead]);
        log.info({ pruned: dead.length }, 'Tokens nativos podados (DeviceNotRegistered)');
      }
    } catch (err) {
      log.warn({ err }, 'Fallo procesando recibos Expo — se reintentará con el próximo envío');
    }
  }
}
```
